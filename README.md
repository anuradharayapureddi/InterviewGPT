# InterviewGPT – AI-Powered Interview Preparation

An AI-powered web application that helps users practice interview questions, receive AI-based answer evaluations, and track their interview performance.

## 🚀 Live Demo

[Try InterviewGPT](https://interviewgpt-awrcfibjrcpdyjrge3amgs.streamlit.app/)

## ✨ Features

- **AI Answer Evaluation:** Evaluate interview answers using the Groq API.
- **Interview Practice:** Practice interview questions and improve answer quality.
- **Performance Tracking:** View technical and communication scores.
- **Interview History:** Review previous interview attempts.
- **Dashboard & Analytics:** Visualize performance statistics using charts.

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- SQLite
- GitHub
- Streamlit Community Cloud

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/anuradharayapureddi/InterviewGPT.git
   ```

2. Open the project folder:

   ```bash
   cd InterviewGPT
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your Groq API key securely using an environment variable named `GROQ_API_KEY`. Never commit your API key to GitHub.

5. Start the application:

   ```bash
   streamlit run app.py
   ```

## 🔐 Security

Keep API keys and private configuration files out of the public repository. Configure deployment secrets through Streamlit Community Cloud.
